# React Bits components

Vendored from [reactbits.dev](https://reactbits.dev) (TS + Tailwind variants) and kept as-is so they can be re-synced.
Local changes to `ProfileCard`: uses `react-bootstrap-icons` instead of `@hugeicons`, and the photo gets `max-w-none` (Tailwind preflight capped its parallax overscan, exposing the right edge on tilt).
